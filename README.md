- 任一有效电池 SOC **严格低于 30%** 时红色提示；未充电时语音“warning，请立即充电”，约每 10 秒一次。确认开始充电即中断/暂停语音。先后 3 次和 10 次实际播报测试完成。

- 当日右臂故障按**用户确认**归档为“电量不足引起的报警”；原始故障事实保留，供电因果未获厂家隔离验证。
