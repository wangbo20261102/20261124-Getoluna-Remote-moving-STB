## 工具窗口为什么显示 0

用户截图是 FXPlatform 的**写入输入框**。检查本地厂家参考源码 `reference/vendor-tool-dialog/UI.py` 可见：1550～1554 行初始化为全 0，5387～5390 行连接重置也恢复全 0；`tools_dialog()` 只绑定这些输入变量，没有从控制器读取工具现值。点 Set tools 才调用 `runtime_set_tool_kd` 下发。因此窗口显示 0，不能作为控制器当前工具补偿已经归零的证据。
