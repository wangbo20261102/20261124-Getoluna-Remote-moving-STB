1. 前言

1.1 文档目的
本说明书旨在帮助客户从拿到天机Gento Luna轮式双臂机器人开始，按循序渐进的路径完成上手使
用，并逐步过渡到二次开发。全书按照真实使用顺序组织，每一章均以前一章为基础，建议首次使用
者按章节顺序阅读操作。


1.2 产品概述
Gento Luna是天机智能推出的高性能轮式折叠人形机器人，搭载Marvin系列M6 Lite机械双臂，采用
独立四转四驱全向移动底盘，基于NVIDIA Orin（可选Thor高算力）边缘AI计算平台，整机26自由度
（不含末端执行器），标配力控功能，支持3D SLAM导航、自主避障、VR遥操作及完整的SDK二次
开发能力。

Gento Luna已符合FCC Part 15B要求，符合美国市场无线通信及电磁兼容相关法规要求。

3.2 使用环境要求
请确保机器人在符合以下环境条件下使用：

1. 环境温度应保持在 -10°C～40°C，相对湿度应低于90%RH（无冷凝）

2. 建议在室内平整、坚固且防滑的地面上运行机器人

3. 请避免在雨雪、积水、强腐蚀性、易燃易爆或大量粉尘等环境中使用机器人

4. 请确保机器人周围具有充足的运行空间，避免人员密集或障碍物复杂区域


3.3 使用前检查
每次启动机器人前，请完成以下检查：

1. 检查机器人整体结构是否完好，各连接部件、机械臂、轮组及末端执行器无松动、变形或损坏

2. 检查急停按钮功能是否正常，并确认能够可靠触发和释放

3. 检查电池电量是否满足当前作业需求，电源连接是否正常

4. 检查控制终端或遥操作终端是否存在故障报警、通信异常或系统错误提示

5. 检查机器人是否安装未经授权的硬件、软件或第三方附件

6. 检查机器人周围环境是否满足安全运行条件

3.5 开机与遥控底盘
1. 插入电池：将电池限位轨道对准小车的限位槽，沿垂直方向顺势垂直插入两块电池

2. 开机：在底盘下方找到电源切换开关按钮，按下按钮亮起绿光即表示开机完成

3. 手柄连接：开机后进行手柄连接，将手柄公头连接至小车车尾处手柄母头，连接成功手柄绿灯闪
  烁

4. 手柄开机：按住home键进入开机状态（长按）

5. 配置D模式：同时两次长按"+"和"-"，第一次第一个灯常亮，第二次后三个灯常亮，手柄进入D模
  式

6. 出仓：底盘初始移动速度为0.6m/s，使用主控盘后退方向键可使Gento Luna移动出仓

3.9 充电方式
Gento Luna提供三种充电方式：手动充电、智能移动充电桩回充（选装）、独立电池充电仓充电（选
装）。


3.9.1 手动充电
Gento Luna配备专用手动充电器，采用智能充电管理技术，支持恒流（CC）和恒压（CV）多阶段充
电模式。充电器防护等级为IP65，适用于常规室内及工业应用环境。

操作步骤：将连接线和电池连接后，将电源接口插入到底盘接口，此时呼吸灯变更为黄色（1Hz频率
闪烁），表示正在充电。请注意充电口插入的正反方向。


3.9.2 智能移动充电桩回充（选装）
支持选配智能移动充电桩，可实现机器人自主回充。当自动回充功能启用，且机器人电池电量
（SOC）低于设定阈值，同时当前无执行任务时，机器人将自动导航至充电站，完成自动对接并开始
充电。

使用前提：自动充电桩已完成安装及调试；地图已完成充电站配置；自动回充功能已启用。


3.9.3 独立电池充电仓（选装）
支持选配独立电池充电仓，用于机器人电池的离线充电与快速轮换。充电仓兼容AC 90–240V宽电压
输入，适用于48V电池系统，集成充满自动停止及多重保护机制。

     Slave的通信管理

5.6运动规划

5.6.1 关节空间运动
不控制末端走直线，直接对各电机关节角度做插值运动，每个轴独立匀速转动，末端轨迹是曲线。速
度快、计算简单，适合大范围快速移位。

●   Start joints：运动起始的6个关节角度，GetCur一键读取机器人当前实时关节角度

●   End joints：目标关节角度

●   Freq 50：运动控制周期50Hz

●   Vel / Acc：关节空间速度、加速度


5.6.2 笛卡尔空间运动
Joints to joints (linear)：输入起点、终点关节角度，控制器自动逆解，保证机械臂末端TCP工具走
空间直线。Vel 100 / Acc 100为笛卡尔空间速度加速度，量程1~1000。




                                   24 / 46
Linear单段笛卡尔直线插补：直接输入末端位姿XYZABC（X/Y/Z空间坐标 + A/B/C欧拉角姿态），两
点之间走标准空间直线，姿态同步平滑过渡。Ref joints为对应点位的参考关节角度，可通过GetCur
读取。

Linear (multi-segment) 多段连续直线：用于连续多拐点作业，可依次添加多个点位，机械臂连续走
完整条折线。Allow Range为点位到达允许误差阈值；ZSP Type / ZSP Params为零空间类型/零空间
参数，约束手臂使得4关节的角度尽量靠近零，然后使得手臂尽可能伸直。

Arms Synchronous Linear双臂同步直线运动：左臂右臂同步启动、同步走完直线，保证双臂运动
时序完全对齐，用于协同抓取、对称作业。

10.1 安全操作注意事项

    以下安全注意事项必须严格遵守，违反操作规范可能导致人身伤害或设备损坏。



10.1.1 使用过程中安全要求


                           44 / 46
1. 请确保机器人始终在额定载荷范围内运行，禁止超负载作业

2. 请根据末端执行器的设计用途进行操作，避免因误用导致设备损坏或安全风险

3. 请确保机器人在平整地面运行；如需跨越坡面，建议坡度不超过产品规定的最大爬坡能力
     （≤10°）

4. 请勿在机器人运动过程中推拉、碰撞或人为阻碍机器人运动

5. 非专业人员不得修改机器人运动控制参数或关闭主动安全保护功能

6. 当机器人出现异常运动、碰撞风险或其他紧急情况时，请立即按下急停按钮，并切断机器人动力
     输出

7. 机器人运行期间，请与机器人保持安全距离，避免进入机械臂、轮组及其他运动部件的工作范围

8. 请勿将手、脚或身体其他部位置于机器人机械臂关节、折叠机构、轮组及其他可能产生夹伤、挤
     压或碰撞风险的区域

9. 在机器人执行自主导航、遥操作或自动任务期间，请确保周围人员已知晓机器人运行状态，并避
     免进入机器人规划路径


10.1.2 通用安全守则
●    区域安全：操作前务必确认机器人工作区域内没有人员或障碍物

●    低速测试：首次运行新程序或调整参数后，务必使用低速进行测试

●    紧急停止：任何紧急情况下，立即使用红色的物理急停按钮

●    参数备份：定期备份系统参数，以防数据丢失

●    专业培训：操作员必须经过专业培训，熟悉操作流程和安全规范

●    急停状态：调试前确认急停按钮处于释放状态，急停按下时机器人不响应运动指令

●    拖动示教：进入拖动示教模式前确认周围安全，手动牵引机器人时注意避免夹手

●    电气安全：请勿在通电状态下插拔控制器线缆，避免短路或电击
